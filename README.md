# CSharp-Level-01
A comprehensive guide to C# fundamentals, covering syntax, data types, control flow, functions, arrays, and basic problem-solving.


# C# Fundamentals (Level 01)

A repository documenting foundational C# concepts, practical exercises, and problem-solving solutions.

---

## 📌 Course / Module Roadmap

- [ ] **01. Introduction & Setup**
  - .NET SDK & Visual Studio / VS Code configuration
  - Basic syntax and `Console.WriteLine`
- [ ] **02. Variables & Data Types**
  - Value types (`int`, `float`, `double`, `decimal`, `bool`, `char`)
  - Reference types (`string`)
  - Type casting & parsing (`Convert`, `int.Parse`, `TryParse`)
- [ ] **03. Operators & Expressions**
  - Arithmetic, relational, and logical operators
  - String concatenation vs. string interpolation
- [ ] **04. Control Flow**
  - `if` / `else if` / `else`
  - `switch` statements and expressions
  - Conditional ternary operator (`?:`)
- [ ] **05. Loops & Iterations**
  - `for`, `while`, `do-while`, and `foreach`
  - Loop controls: `break` and `continue`
- [ ] **06. Methods & Functions**
  - Parameter passing (`by value`, `ref`, `out`)
  - Method overloading
  - Scope and return values
- [ ] **07. Arrays & Collections**
  - 1D, 2D (matrix), and jagged arrays
  - Basic array operations (`Array.Sort`, `Array.Reverse`)
  - Introduction to `List<T>`

---
